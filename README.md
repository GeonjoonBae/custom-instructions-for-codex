# Custom instructions for Codex

## English

This repository provides a `AGENTS.md` instruction set for coding and research workflows.

### Purpose

The instruction set is designed for agentic coding environments that read project-level guidance from an `AGENTS.md` file. It emphasizes source accuracy, conservative code changes, UTF-8-safe file handling, and practical verification.

### Usage

Place `AGENTS.md` at the root of a project, or adapt its contents into your own environment-specific instruction file.

### Acknowledgements

This repository's agent-instruction design was developed with substantial reference to `CLAUDE.md` from [`forrestchang/andrej-karpathy-skills`](https://github.com/forrestchang/andrej-karpathy-skills), and was further adapted and expanded for Codex-oriented workflows and my own research and coding environment.

The original repository describes its guideline set as derived from Andrej Karpathy's observations on LLM coding pitfalls. This repository is an independent adaptation and is not affiliated with or endorsed by Forrest Chang or Andrej Karpathy.

See [`NOTICE`](./NOTICE) for attribution details.

## 한국어

이 저장소는 코딩 및 연구 워크플로우를 위한 `AGENTS.md` 지침 세트를 제공한다.

### 목적

이 지침 세트는 프로젝트 단위의 `AGENTS.md` 파일을 읽는 에이전트형 코딩 환경을 염두에 두고 작성됨. 핵심 초점은 출처 정확성, 보수적 코드 수정, UTF-8 기반 파일 처리, 그리고 실용적 검증에 있음.

### 사용 방법

프로젝트 루트에 `AGENTS.md`를 두어 그대로 사용하거나, 자신의 환경에 맞게 필요한 부분을 조정하여 사용할 수 있음.

### 참고 및 출처

이 저장소의 에이전트 지침 설계는 [`forrestchang/andrej-karpathy-skills`](https://github.com/forrestchang/andrej-karpathy-skills)에 제공된 지침 문서인 `CLAUDE.md`를 상당 부분 참고하여 작성되었으며, 이후 Codex 중심 워크플로우와 사용자의 연구 환경에 맞게 수정 및 확장하였음.
